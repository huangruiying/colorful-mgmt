# 10 注入与 XSS 专项

## 职责

专项检测“输入未清洗”类漏洞：SQL 注入、命令注入、模板注入、XSS、SSRF、反序列化、路径穿越。通用 SAST 交给 08，依赖问题交给 11。

## 何时使用

- 新增或修改用户输入入口（接口参数、页面表单、上传、外部回调）
- 新增“用户输入 → SQL / 命令 / 模板 / 网络请求 / 文件路径”的调用
- Workflow B 的分支

## 执行

- 给出完整的 Source → Sink 链路，不做单点判定。
- 本项目重点检查：MyBatis-Plus 动态 SQL 不拼接用户输入（`last()` 只放 PageQuery 生成的分页片段）；管理页面渲染模型回答、平台内容等外部文本时防 XSS；向外部地址发请求（大模型网关、平台地址）时防 SSRF；Fastjson 反序列化不开启 autoType。
- 修复建议写具体模式（参数化、转义、白名单），附 OWASP / CWE 编号。

## 交付

- 漏洞点：Source → Sink、文件:行号、严重度、触达条件
- 具体修复模式，由 04 / 05 实施后进入 09
