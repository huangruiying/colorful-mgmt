# 07 文档生成

## 职责

生成开发与维护所需的工程文档：模块说明、关键流程、配置与排障说明，以及技术详细设计。不写接口契约和独立接口文档（03 + api-doc.md），不写 PR 描述（21）。

## 何时使用

- 新模块或现有模块缺少说明
- 需要技术详细设计、技术方案或发版影响分析
- 功能落地后需要同步验收记录或服务器执行步骤

## 执行

- 详细设计必须按 [tech-design-doc.md](../../rules/tech-design-doc.md) 先收集信息再写，不用 README 结构代替。
- 文档放在 `.doc/`；先解释为什么，再说明怎么用；与代码同步，不编造 API 或字段，不大段复述实现。

## 交付

- 完整文档文本与落盘路径
- 文档与代码可能脱节的地方
