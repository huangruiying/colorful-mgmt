# 06 单元测试

## 职责

为新写或刚改的代码补行为级单元测试，覆盖关键业务行为与边界。不做真实接口回归（31）、日志归因（14）和代码复核（09）。

## 何时使用

- 04 实现后、05 重构后的默认步骤（Workflow A / D / E）
- 修复缺陷前先复现问题

## 执行

- 遵守 [testing.md](../../rules/testing.md)，mock 准则以其 §7 为准。
- 测试名表达场景，断言精确；覆盖正常、边界、异常路径；不为凑覆盖率写无断言测试，不用 mock 让测试必然通过。
- 运行相关 Maven 测试，分别记录通过、失败和无法运行的原因。

## 交付

- 新增 / 修改的测试清单及覆盖的行为
- 运行结果；被 mock 掩盖的风险和未覆盖的路径
