# 03 接口契约设计

## 职责

定义接口长什么样：路径与方法、请求与响应字段、失败场景、鉴权、兼容策略；需要给调用方的独立接口文档时按 api-doc.md 输出。不写实现（04）；完整的技术详细设计交给 07 并按 tech-design-doc.md 输出。

## 何时使用

- 新建或修改接口结构
- 给管理页面、第三方或其他调用方提供接口文档
- 同一字段在不同接口里语义不一致

## 执行

- 遵守 [api-doc.md](../../rules/api-doc.md) 中的本项目接口约定（直接返回业务对象、分页用 PageResponse、出错返回 ProblemDetail、写请求带 XSRF 令牌）和 [naming.md](../../rules/naming.md)。
- 字段标注类型、必填、默认值、单位、枚举范围；路径用资源名词，不暴露表名和内部类名。
- 写接口说明幂等策略；不兼容的变更说明迁移方式，字段只增不删，废弃前先标注。

## 交付

- 完整接口定义，或按 api-doc.md 写好的接口文档
- 兼容性风险、字段歧义和迁移建议
