# `.claude` 上下文治理记忆

- `.claude` 的核心目标是“按需加载”：入口文件只放路由、索引、触发条件，细节下沉到 `agents/`、`workflows/`、`rules/`、`memory/`。
- 优先使用“引用而非复刻”，避免在多个文件重复维护同一规则。
- 2026-11-19 用户确认这套 `.claude` 只服务本项目：不保留其他项目（支付、Python 服务）的规则；项目约定只放跨模块约定，模块决策放 `rules/modules/` 按触发读取；Agent 文件统一短格式（职责 / 何时使用 / 执行 / 交付），删除本项目用不到的角色。
- 多候选 / 自定义编排和风险升级集中在 `workflows/routing-policy.md`，普通单 Agent / 单 Workflow 任务不读取。
- 大段好坏示例会消耗上下文，除非对 AI 执行很关键，否则优先删减、改成最小示例，或引用专题规则。
