# 项目记忆索引

本目录只记录长期有效、跨会话有复用价值的内容；临时任务细节不要写入 memory。

**核心** 不要没有任何凭据的时候就下结论

## 加载原则

- 每次先读本索引。
- 只在任务命中对应主题时继续读取专项记忆文件。
- 强执行规范放 `rules/`，memory 只记录背景、决策、协作偏好，不重复维护规则正文。

## 专项记忆

| 主题 | 何时读取 | 文件 |
