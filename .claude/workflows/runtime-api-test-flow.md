# 真实接口回归与运行环境

只有需要真实请求服务时使用；“全量单测”不自动变成付费模型或对外发布回归。单测设计见 [测试规范](../rules/testing.md)，环境位置见 [运行线索](../memory/runtime-env.md)。

## 1. 先确定契约与前置条件

从用户范围、接口文档或当前分支差异定位 Controller → Business → Service → DAO 与模型；字段先分清强过滤、辅助选路、上下文和兼容字段，再写负向断言。传入不存在值仍返回数据不一定是 bug。

核对服务地址、接口范围、必要入参、日志、数据库和外部条件。只做 HTTP 请求不强制索取启动配置或数据库；需要编译、启动、重启或查库才补对应条件。能从代码和已有配置查到的不问，剩余缺口一次性列出，只暂停依赖该条件的步骤。

登录和 XSRF 保持真实安全边界；凭据只从环境或已授权的安全来源读取，绝不写入脚本和报告。无登录条件则记录未测，不放行匿名请求。

## 2. 编译、启动与重启

- 本机优先读 `.idea/runConfigurations/`、`.idea/workspace.xml` 的 RunManager，再查项目 SDK、模块和 Maven 配置；用户明确指定命令优先。配置可能含凭据，只提取必要字段，不整份输出。
- 核对主类、模块/classpath、工作目录、JDK/Maven、settings/profiles、VM/程序参数和环境变量。不能用 shell 默认值冒充 IDE 配置；没有 IDE 配置且用户未提供明确构建/启动命令时，只完成静态分析与不依赖启动配置的验证，列明缺口，不凭环境线索猜测真实配置。IDE 与构建或路径冲突时先报告，影响执行正确性则暂停相应步骤。
- 默认以等价命令执行，不操作 IDE GUI。用参数数组或正确引用保存参数边界，不对 `ps` 输出简单 split、eval 或正则删参；无法还原就不擅自重启。
- 重启前查 PID、端口、主类与进程来源，只停归属确定的目标。记录启动方式、PID、工作目录和日志位置；命令与环境摘要必须脱敏。
- 源码变化要先构建所需产物，不能沿用旧 classpath/classes 冒充已部署新代码；启动形式按真实配置，不一律禁止 jar 或强制重新打包。
- 配置注入不假定热更新，先核对绑定机制；必要时重启。调试需实际原因，JDWP 不自动对外开放。

启动成功逐项确认：进程存活、目标端口归属、HTTP 可达、所需业务接口行为。401/404 只证明 HTTP 可达，不能写业务验证成功；连接失败结合代理、端口、网络隔离与日志判断，不默认归咎沙箱。

## 3. 数据、请求与外部替身

优先真实可用的已有测试样例；在已授权的测试范围内补最小数据，写明表、主键、用途与保留状态，不覆盖已有业务数据。临时库导入 SQL 先检查 CREATE DATABASE/USE，确认不会切回真实库。

超过两个接口步骤时优先在项目约定的测试目录写可执行脚本，每步断言 HTTP、关键字段和必要落库结果；请求失败必须查对应日志。localhost curl 按环境决定 `--noproxy '*'`，失败输出脱敏，不能直接打印 Cookie、完整请求或原始敏感响应。

外部依赖不可用先真实请求取证，可用测试代码或本地 HTTP stub 验证内部逻辑，标清未验证的真实链路。不得在生产源码加临时绕路或改鉴权制造通过。替身、临时配置与日志结束前清理，用户明确保留时仅留测试目录并说明范围。本流程新增的测试数据默认保留并在报告列主键；用户要求清理时只清本次明确标识的数据，未授权不删除已有数据。

脚本配置按实际需要用 BASE_URL、AUTH_COOKIE、XSRF_TOKEN、DB_HOST/PORT/NAME/USER/PASSWORD、CURL_NO_PROXY 等环境变量，不能为不使用的连接额外索取凭据。

## 4. 归因与修复

| 归因 | 处置 |
|---|---|
| 代码缺陷 | 证据定位后按公共流程最小修复 |
| 环境 | 核对服务、代理、端口、容器与配置，不长期修改业务逻辑掩盖 |
| 外部依赖 | 标明真实条件未满足；替身结果另列 |
| 数据 | 核对配置与样例，按授权补最小测试数据 |

在原任务授权内可做一次最小修复、一次必要重启和一轮针对失败及受影响接口的复测。仍失败则停止自动修复循环、继续取证并报告阻断；用户明确要求继续排查时开启新一轮有依据的诊断。修复后先做必要编译/静态检查，失败不继续重启；复测只针对失败及受影响路径，更新同一报告。接口语义或产品规则变化先确认，不借自愈扩展范围。

## 5. 报告与清理

报告路径和命名遵守 [项目工程记忆](../memory/project-practices.md)，分支含斜线时文件名转换为安全短名。包含范围、时间、服务、脱敏请求结果、通过/失败/未测清单、日志与代码证据、归因、修复/重启/复测、未覆盖项、测试数据、替身和清理状态。

区分最终源码与当前运行实例，写清实际 JDK/Maven 和配置来源；复核最终 diff/status。单次请求成功不代表异步任务完成、草稿公开发布或服务器已更新。
