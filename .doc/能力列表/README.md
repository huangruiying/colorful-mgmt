# 能力列表

系统内每项能力一个文件：分层图、交互图、核心类、新业务接入改哪里、约束、已知待改。只写核心点，细节看源码注释。

## 业务能力

| 能力 | 一句话 |
|---|---|
| [诊断方案](诊断方案.md) | 按地域生成并审核诊断问题，连同被测渠道保存为方案 |
| [诊断任务](诊断任务.md) | 冻结方案后逐条联网调用模型，记录每次回答 |
| [诊断报告](诊断报告.md) | 两段生成报告：逐条判定回答，再汇成七个页签，可导出网页 |
| [内容优化](内容优化.md) | 用模型按策略优化一篇内容并保存记录 |
| [多平台内容投放](多平台内容投放.md) | 把确认稿预发布为各平台草稿，后台逐条执行并回读确认 |
| [平台浏览器登录](平台浏览器登录.md) | 扫码、短信、密码、第三方授权登录内容平台，保存登录态 |
| [项目档案与导入导出](项目档案与导入导出.md) | 项目档案的新建、删除，以及整个项目数据的导出与导入 |

## 技术能力

| 能力 | 一句话 |
|---|---|
| [浏览器人工接管](浏览器人工接管.md) | 无头浏览器遇到滑块、短信验证等，把画面推到管理页由人操作 |
| [大模型渠道与调用](大模型渠道与调用.md) | 库表配置渠道，按策略 Bean 路由到各厂商，联网与引用解析 |
| [提示词管理](提示词管理.md) | 提示词存库、按版本保存与回滚，各业务按约定版本取用并填充 |
| [管理后台登录与访问控制](管理后台登录与访问控制.md) | 唯一管理员登录、失败锁定、XSRF、统一 ProblemDetail 错误 |
| [前端公共能力](前端公共能力.md) | 管理页共用的请求、导航、弹窗、分页、Markdown 展示等模块 |
